THE SHORT, USEFUL GUIDE

Pixels, KB and the space between.

An upload form asks for “under 100 KB” and “300 × 300 pixels”. They measure different things. Here is how to get both right.

Pixels are dimensions. KB is file size.

A 300 × 300 pixel photo has 300 pixels across and 300 down. Its file size depends on format, quality and how much detail the picture contains. Changing only the width does not guarantee a particular file size.

HyperCompressor uses 1 KB = 1,000 bytes for size limits. Some systems display 1,024 bytes as a KB. The conservative limit helps the output stay below either interpretation of a maximum.

Choose the right format

FormatUseful forKeep in mind
JPGPhotos and most application formsLossy; no transparency. Transparent areas become white.
PNGLogos, diagrams and transparencyLossless compression; a quality slider does not reduce its size.
WebPImages for modern websitesSupports transparency; some forms do not accept it.

When a form requires exact pixels

Enter both dimensions in the pixel resizer. “Fit” keeps the whole image with padding. “Crop” fills the frame by removing edges. “Stretch” can distort a face or handwriting, so use it only when that is intentional.

When a form requires a maximum KB size

Use 20 KB for a tight limit, or choose 50 KB, 100 KB or 200 KB. The tool first tries lower encoding quality, then smaller dimensions if exact pixels were not requested.

When a form also requires a minimum

Enter that value in the optional minimum-size field. The tool warns if the result is too small. It does not add meaningless padding bytes to pretend the image has more detail. Try a better original, higher quality or larger permitted dimensions.

Before you submit

  • Open the downloaded file and check the face, handwriting and document text.
  • Confirm the extension is accepted by the portal.
  • Check minimum size, maximum size and required pixel dimensions.
  • Read the current application instructions for backgrounds, dates and live-capture rules.
