Add a Name and Date Below a Photo Without Covering the Face

By HyperCompressor · Published 23 October 2026 · 3 min read

Some application instructions ask for text on a photograph. When yours does, put it in a clearly readable strip and check the complete exported image. Do not add a label simply because another exam once required one.

Read the exact wording first

Check whether the requested date means the date the photograph was taken, a date of birth or something else. Check its required display format and whether the name must match an application field. Our tool labels its date input “Photograph date”; it does not verify when the image was captured.

We do not claim that name/date stamping is universally required for NEET, SSC, UPSC or railway applications. Use the current notice and the upload instructions for your own form. For NEET, see our official-source photo guidance rather than assuming an old tutorial still applies.

Make the strip

  1. Open Add name and date to photo and choose a clear image.
  2. Enter the requested name or label. It is rendered as text, not as HTML or a link.
  3. Add the actual photograph date if needed. Choose YYYY-MM-DD or DD-MM-YYYY.
  4. Leave the maximum KB field blank for the first preview, so you can judge the text without a tight compression target.
  5. Create the preview, read every character and download the JPG when correct.

The strip changes the image height

The original photo remains above the new white strip. Adding space underneath avoids covering the chin or clothing, but makes the combined image taller. It does not automatically preserve an application's original pixel requirement.

If exact dimensions are required, resize the full combined output in the pixel resizer. Use Fit to retain all the text. Crop may cut off the strip, while Stretch changes proportions. A very small final image can make the text unreadable even if its dimensions are technically correct.

Apply the file-size limit last

After checking the text, choose a maximum KB if the portal specifies one. Smaller output can reduce readability. Open the downloaded result and use the upload requirement checker to compare it with the minimum, maximum, format and pixel rules.

Common mistakes to avoid

  • Entering today's date automatically instead of the real photograph date.
  • Adding the strip to an image that already has the same label.
  • Assuming the added text proves the age or authenticity of a photograph.
  • Submitting a renamed file instead of a genuinely converted JPEG.

Keep the unlabelled original for forms that require a plain photo. If an upload still fails, follow the photo upload troubleshooting guide.
