Photo Upload Rejected? Check KB, Pixels and File Format

By HyperCompressor · Published 23 October 2026 · 3 min read

A file can look fine and still fail an upload check. Start with the error message and the exported file you are actually submitting. Changing random settings can create a second problem without fixing the first.

Check the original file against the form

Open the photo upload checker, choose your image and enter the form's requirements. It reports separate results for minimum bytes, maximum bytes, exact width, exact height and format. Leave a requirement blank when the form does not specify it.

Why “200 KB” can be ambiguous

A label rounded to 200 KB may conceal a file slightly above the boundary. Some software uses 1,000 bytes per KB; other software uses 1,024, technically KiB. Our checker offers both conventions. If a portal does not explain its units, a file comfortably below a maximum is safer than aiming for the last byte. A minimum still needs checking separately.

Pixels and file size need separate fixes

For an exact 300 × 300 requirement, use the exact pixel resizer. Fit preserves the whole image with padding; Crop fills the frame by removing edges. Neither option verifies a person's face position. For a KB limit without fixed dimensions, use 100 KB compression or enter a custom maximum.

Renaming PNG to JPG is not conversion

The extension is a filename label. A PNG renamed to .jpg can still contain PNG data. Use PNG to JPG conversion to create a JPEG-encoded file. Transparency becomes white in our JPG output. Keep the original if transparency is needed elsewhere.

When the technical checks pass

A portal may apply rules beyond bytes and pixels: background, face coverage, document content or a separate live-capture step. Read its instructions. A local checker cannot confirm server availability, account status or acceptance. If the site gives a session error, follow its own retry or support instructions rather than repeatedly degrading your image.

For the underlying browser export behaviour, see MDN's Canvas image export documentation. For a related exam example, read our NEET photo and signature reference.
