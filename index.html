Common questions

Quick answers about image size, rejection and privacy.

Why was my exam photo rejected?

Common reasons include incorrect pixel dimensions, an image that exceeds the portal's file-size limit, or an unsupported format. Use the relevant portal page on HyperCompressor and follow the current requirements shown there.

Can I compress an image to 20KB, 50KB, 100KB or 200KB?

Yes. HyperCompressor provides dedicated tools for each of these target file sizes, as well as custom resizing controls.

Are my photos uploaded to a server?

The image processing tool is designed to work in your browser. Your selected image is processed locally rather than being sent to a HyperCompressor upload server.

Can I use HyperCompressor on my phone?

Yes. The interface is responsive and the image tools can be used from modern mobile browsers as well as desktop browsers.
