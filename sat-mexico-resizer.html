SAT and e.firma image requirements

For the SAT credential-photo preset on this page, the configured target is 420×540 pixels with a maximum file size of 50KB. The other presets are configured for browser-side compression with maximum sizes of 300KB for an INE document and 500KB for a proof-of-address document.

The image is read and processed locally by your browser. The page does not need to upload the selected image to a processing server.

How do I resize a SAT photo to 420×540 pixels?

Select “Foto Credencial (SAT)”, choose your image, then click “Resize & Download”. The tool crops the image to the 420×540 target and compresses the output toward the 50KB limit.

Can I use the tool for INE or proof-of-address files?

Yes. Select the relevant preset. The tool keeps the document's aspect ratio and compresses it toward the configured maximum file size.
